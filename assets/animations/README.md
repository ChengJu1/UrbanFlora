# Lottie animations

Drop here any Lottie `.json` files we want to play on key interactions —
for example `new_species.json` shown after a save.

Free candidates:

- https://lottiefiles.com/search?q=leaf (MIT / CC0 filter)
- https://lottiefiles.com/search?q=badge

The UI references these via the `lottie` package; see the `achievements`
feature for wiring.
