# Image assets

This folder will contain:

- `splash_logo.png` — 512x512 PNG, drawn or exported from Figma, used by
  `flutter_native_splash`.
- `app_icon.png` — 1024x1024 PNG consumed by `flutter_launcher_icons`.
- screenshots of the running app for the README.

Until real artwork is added, `flutter_native_splash` will just render the
background colour, which is still acceptable for the first build.
